# CONTEXTO: tu bandeja de entrada

Deja aquí tus entrenos tal como los tengas: notas del móvil (.md, .txt), el CSV de una app, un export de un chat (Telegram, WhatsApp) o fotos de tu libreta. Después usa `/gymhub:refresh`.

Lo que se importa se mueve, intacto, a `CONTEXTO/procesado/AAAA-MM-DD/`. Este fichero se ignora.
