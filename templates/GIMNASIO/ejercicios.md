# Catálogo de ejercicios

Lo usa gymhub para reconocer tus ejercicios, se llamen como se llamen. Puedes añadir filas o alias cuando quieras.

- **id:** no se cambia nunca. Para unificar dos ejercicios, pon el id de uno como alias del otro y gymhub junta su historial.
- **grupo** y **secundarios:** pecho, dorsal, espalda-alta, trapecio, lumbar, hombro, biceps, triceps, antebrazo, abdomen, cuadriceps, femoral, gluteo, aductor, gemelo.
- **carga:** barra, mancuerna, maquina, polea, peso-corporal, kettlebell, banda, otro.
- **patron:** empuje-horizontal, empuje-vertical, tiron-horizontal, tiron-vertical, cadera, rodilla, aislamiento, core, cardio.
- **principal:** `si` en el ejercicio de referencia de cada patrón (para comparar la fuerza entre patrones).
